0. 部署与实现方案

  • 不做原生 App:只做 Web / PWA。"iPhone 竖屏 / 横屏"仅是画布尺寸参照。
  • 托管:GitHub Pages 静态托管(纯前端、无后端;进度与错题本存浏览器 IndexedDB/localStorage)。
  • 仓库与访问链接(用户已确认):仓库 fymdchenwei/yuwen(公开)→ https://fymdchenwei.github.io/yuwen/。
  • 项目站点会部署在子路径 /yuwen/ 下,因此代码里所有资源路径、manifest 的 start_url/scope、Service Worker 的 scope 都要用相对路径或 /yuwen/ 前缀。
  • 当前状态:未向该仓库写入任何内容,开发待用户审完本效果图后启动。
  • 添加到桌面(界面见 H4):manifest.webmanifest(名称、192/512 图标、display: standalone、主题色、orientation: any)+ iOS 额外加 apple-touch-icon 与 apple-mobile-web-app-capable;iOS Safari「分享 → 添加到主屏幕」,安卓 Chrome「安装应用 / 添加到主屏幕」。
  • 离线支持:Service Worker 预缓存 App Shell(HTML/CSS/JS)、字体子集、各类题库 JSON;首次联网打开后无网络也能练习与记录进度;新版本后台静默更新、下次打开生效。
  • 数据保存与备份:进度只在本设备;换机/清浏览器数据会丢失 → 「我的」提供 JSON 导出/导入备份(H4 有提示)。iOS 对长期不用的站点可能清理存储,需提示"添加到主屏幕后更稳"。
  • 横竖屏适配:响应式(CSS Grid + clamp() 字号 + @media (orientation: landscape))。竖屏底部 Tab;横屏改为左侧窄导航栏(66px),内容区左右分栏(左:题干/路径,右:选项/操作)。iPad 同理。
  • 听写读音:使用浏览器 Web Speech API(speechSynthesis,lang=zh-CN)读词,读音来自系统语音,离线可用性取决于设备是否装了中文语音(iOS/安卓一般自带)。需在实现时实测;无中文语音时降级为"显示拼音 + 家长朗读"。
  • 提醒:网页/PWA 无法可靠地在后台推送(尤其 iOS),所以"隔天重考"提醒以首页顶部提醒条为主(D3 已画);可选下载 .ics 日历提醒。不承诺系统推送。
  • 字体:界面 Noto Sans CJK SC(iOS 回退 PingFang SC);正文楷体感用开源「霞鹜文楷 LXGW WenKai」(OFL)。效果图 fonts/wenkai-subset.ttf 由完整字体(v1.510)按本套图实际用字裁剪(src/subset.py),上线时同样子集化并随 Service Worker 缓存。

1. 设计思路

  1. 15 分钟一条线:首页只回答"今天做什么":错题重考 → 古诗词 → 阅读理解 → 快问快答,每段有时间;其余类别可随点随练。
  2. 五类练习共用一个外壳:同样的顶部进度条、底部反馈条、星星、徽章、错题本——换玩法,不换壳。
  3. 错误不惩罚:答错用粉色 + 鼓励语,并自动进错题本,按 明天 → 3 天后 → 7 天后 复习;连续 3 次答对"毕业"。
  4. 理解优于猜:阅读理解必须划出依据句才给分;成语接词后还要选/说出意思。
  5. 进度可见:今日计划步骤条、连续打卡周历、五类进度条、徽章墙。

4. 每日 15 分钟流程(示例配比)

步骤 内容 时长 说明
① 错题重考 3 分 取错题本中"今天到期"的题(五类混合),没有到期题则跳过并顺延时间
② 古诗词 5 分 接着上次关卡(如《示儿》第 2 关),约 3 关
③ 阅读理解 5 分 1~2 题,一篇短文
④ 快问快答 2 分 5 题
  • 听写、成语接龙不固定在 15 分钟里,按星期轮换(如 周一/三/五 听写,周二/四 成语),或孩子自选加餐;首页卡片标"今日主练 / 重考 N 词 / 今日加餐"。
  • 完成 15 分钟计划算"打卡 1 天";连续天数驱动徽章(如"连续 7 天")。
  • 计划时长、轮换方式为示意,可由家长调整。

8. 内容核实情况

已核实(联网,与词典/多站点互证)
- 成语释义:发愤图强 ——"下定决心,努力谋求强盛"(汉典/国语辞典等);意气风发 ——"形容精神振奋,气概豪迈/志气昂扬"(界面写作"精神振奋,气概昂扬");一心一意 ——"心思专一、没有别的念头"(界面写作"心思专一,没有别的想法")。近义成语"奋发图强"为词典所列近义词。
- 成语接龙链:一心一意 → 意气风发 → 发愤图强 → 强…… 均为首尾字相接(意、发、强 取自成语各自的尾字/首字)。
- 文学常识(仅用公认无争议项):李白称"诗仙"、杜甫称"诗圣";《论语》记录孔子及其弟子言行;《西游记》作者吴承恩;《朝花夕拾》作者鲁迅、为回忆性散文集。
- 古诗正文:沿用 v1 已核实的《静夜思》《示儿》;其余诗只显示诗名。诗目见 v1 核实结果。

未核实 / 需在题库入库前处理
1. 三年级上册「古诗三首」(第 4 课、第 20 课)篇目:未核实,不上架不出题(沿用 v1)。
2. 四、五年级下册新版教材(2027 春)尚未出版,不收录。
3. 二年级下册《绝句》与三年级下册《绝句》具体对应篇目需再核(沿用 v1)。
4. 成语 I1 里的干扰项"发人深省""发扬光大"是成语本身真实存在,但本稿未逐条核对其释义(界面未展示其释义);入库时每个成语都必须先核实释义再上架,不确定的一律不用。
5. 成语"近义词"页签本次只画了入口页签,未出近义词题目界面,所以没有展示近义词对。
6. 阅读短文与题目为原创示例,正式题库需由家长/老师审阅(如"一般"一词的指代、依据句唯一性)。
7. 文学常识题库:五年级应掌握范围未核实,本稿只取上述确定项;入库时只收有明确出处、无争议的题。
8. 各类"每日时长/复习间隔(1/3/7 天)/毕业规则(连续 3 次)"为学习科学常用做法的设计假设,非教材规定。
9. Web Speech 中文读音质量与离线可用性依设备而异,需真机实测。
10. iOS PWA 的存储清理、通知限制以实现时真机表现为准。

9. 供用户审看的要点

  1. 首页:15 分钟 4 步配比(3/5/5/2)和"今日主练/加餐"轮换是否合适?五类入口顺序?
  2. 听写:孩子在纸上写 + 自核(自评)是否可接受?是否需要家长代核?自核错字标记是否太繁琐?
  3. 阅读找证据:"划对依据句才得分"的评分规则(选对 1 分 + 划对依据 1 分 + 不多划 1 分,示意)是否合适?短文长度、是否每次 1~2 题?
  4. 成语:"接词 + 选意思"两步是否太长?"说出意思由家长点对/不对"是否要保留?
  5. 文学常识:倒计时是否需要(压力 vs 趣味)?是否只做选择题?
  6. 错题本:五类混排 + 按复习日期排序是否直观?"连续 3 次答对毕业"规则?
  7. 提醒:PWA 只能首页提醒条 + 日历文件,是否可接受?
  8. 横屏:是否需要横版覆盖全部页面(本稿只画 5 屏,其余按同规则推导)?
  9. 添加到主屏幕:图标暂为占位("学"字橙底),App 名"每日十五分钟"为暂定名。
  10. 开发启动前需用户确认以上要点;目前未创建或写入任何 GitHub 内容。
